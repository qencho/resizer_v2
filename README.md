# Resizer (Forge 1.20.1)

Сборка без установки чего-либо: загрузи папку в репозиторий GitHub,
вкладка Actions -> build -> Artifacts -> resizer-jar. Внутри будет resizer-1.0.0.jar.
Положи его в папку mods (Forge 1.20.1, версия 47.x).

Локально: gradle build (нужны JDK 17 и Gradle 8.1.1), jar в build/libs/.
